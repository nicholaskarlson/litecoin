# Security Policy

## Reporting a Vulnerability

At UseItCoin, we take security seriously. If you discover a vulnerability in the UseItCoin codebase, please report it as soon as possible.

**To report security issues, send an email to:**  
📧 **security@useitcoin.com** (For security vulnerabilities only, not general support.)

When reporting a security vulnerability, please provide:
- A **detailed description** of the issue.
- Steps to **reproduce** the vulnerability.
- **Potential impact** and any recommended fixes, if applicable.

We strongly encourage responsible disclosure and will work with researchers and developers to address security concerns as quickly as possible.

## Security Best Practices for Developers

To help maintain the security of UseItCoin:
1. **Keep your software up to date** – Regularly update to the latest version of UseItCoin to receive security patches.
2. **Verify signatures** – Always verify official UseItCoin releases using provided PGP signatures and checksums.
3. **Use strong passwords and encryption** – If running a UseItCoin node or wallet, use strong passwords and enable encryption for added security.
4. **Beware of phishing attempts** – Official communications will only come from `useitcoin.org`.

## Disclosure Policy

- We will acknowledge receipt of vulnerability reports within **48 hours**.
- We aim to resolve confirmed security issues within **7–14 days**, depending on severity.
- Critical vulnerabilities may result in an **emergency security release**.

Thank you for helping keep **UseItCoin** secure!
